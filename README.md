✨ Interactive Features

🌙 Light/Dark theme toggle
📄 One-click resume download
🎯 Dynamic project filtering
⌨️ Typing animation
📱 Responsive navigation
📩 Contact form validation
⬆️ Back-to-top button
✨ Scroll animations

Resume Download — Clicking the Resume button automatically downloads my CV.
Theme Toggle — A single button switches between Light and Dark mode.
Dynamic Navbar — Navbar links smoothly scroll to the selected section.
Active Navigation — Highlights the current section while scrolling.
Project Filter — Filter projects by technology/category without reloading.
Interactive Project Cards — Hovering over cards reveals project details and links.
Typing Animation — Displays different developer roles with an animated typing effect.
Scroll Animation — Sections smoothly appear as the user scrolls.
Back to Top — Button appears after scrolling and smoothly returns to the top.
Contact Form Validation — Checks required fields and validates email before submission.
Single Theme Button — One button detects the current theme and toggles Light ↔ Dark automatically.
Responsive Menu — Hamburger menu opens/closes navigation on mobile devices.
Image Preview — Clicking a project image opens it in a larger preview.
Skills Animation — Skill bars/cards animate when they become visible.
Toast Notifications — Shows a small success/error message after user actions.
